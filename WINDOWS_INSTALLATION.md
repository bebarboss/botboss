# 🎫 BOTBOSS - Windows Installation Guide

## 📥 Installation

### Method 1: Portable Executable (Recommended)

1. **Download** `BOTBOSS.exe` from [Releases](https://github.com/bebarboss/botboss/releases)
2. **Extract** or **Place** the file anywhere on your computer
3. **Double-click** `BOTBOSS.exe` to run

No installation needed - just run!

### Method 2: ZIP Archive

1. **Download** `BOTBOSS-Windows.zip`
2. **Right-click** → **Extract All**
3. Open the extracted folder
4. **Double-click** `BOTBOSS.exe`

---

## ⚠️ First Launch Security Warning

Windows may show a warning:
> **"Windows protected your PC"**

**Solution:**
1. Click **"More info"**
2. Click **"Run anyway"**
3. Click **"Yes"** if prompted

This is normal for unsigned applications. The app is safe!

---

## 🚀 How to Use

1. **Launch BOTBOSS.exe**
2. **Enter the website URL** (e.g., https://booking.thaiticketmajor.com)
3. **Click "Connect"** to open Chrome in debug mode
4. **Set your schedule** and preferences
5. **Click "Start"** to begin automation

---

## 📋 Requirements

- **Windows 10 or later** (64-bit)
- **Google Chrome** - Must be installed
  - Download from: https://www.google.com/chrome/
- **Minimum 500MB free disk space**

---

## 🔧 Troubleshooting

### "Chrome not found"
**Solution:** Install Google Chrome first
1. Go to https://www.google.com/chrome/
2. Download and install Chrome
3. Restart BOTBOSS

### "Windows protected your PC" message
**Solution:** See "First Launch Security Warning" section above

### Application crashes
1. Make sure Google Chrome is fully updated
2. Try running as Administrator:
   - Right-click `BOTBOSS.exe`
   - Select **"Run as administrator"**

### Port already in use (9222)
- Close other Chrome instances
- Or restart your computer

---

## 💻 Running as Administrator

If you need admin privileges:

1. Right-click **BOTBOSS.exe**
2. Select **"Run as administrator"**
3. Click **"Yes"** on the UAC prompt

---

## 🔐 Antivirus Warning

Some antivirus software may flag the executable. This is a **false positive** - the application is safe.

If prompted:
- Click **"Allow"** or **"Run anyway"**
- Add BOTBOSS to your antivirus whitelist (if available)
