# BOTBOSS v1.0.0

## 🎉 First Release - macOS App

### Features
- ✅ Automatic ticket clicking bot
- ✅ User-friendly GUI built with PyQt6
- ✅ Chrome debugging integration
- ✅ Scheduled clicking based on time
- ✅ Start/Stop functionality

### Requirements
- **macOS 11 (Big Sur) or later**
- **Apple Silicon (M1/M2/M3)** supported
- **Google Chrome** must be installed

### Installation

#### Method 1: Using DMG (Recommended)
1. Download `BOTBOSS.dmg`
2. Double-click the DMG file
3. Drag **BOTBOSS** to the **Applications** folder
4. Launch from Applications

#### Method 2: Using ZIP
1. Download `BOTBOSS-macOS.zip`
2. Extract the zip file
3. Move `BOTBOSS.app` to the **Applications** folder
4. Launch the app

### First Launch

On first launch, you may see a security warning: *"BOTBOSS cannot be opened because it is from an unidentified developer"*

**To fix:**
1. Right-click (or Control+click) on **BOTBOSS.app**
2. Select **"Open"**
3. Click **"Open"** again in the dialog
4. The app will now run (you only need to do this once)

### Usage
1. Launch BOTBOSS
2. Enter the website URL
3. Click "Connect"
4. The bot will start working automatically

### Notes
- Make sure Google Chrome is installed before using
- The app will open Chrome in debug mode
- Keep the app window open while the bot is running
